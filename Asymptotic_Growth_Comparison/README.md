# Asymptotic Growth Comparison

A beginner-friendly mini project that visualizes Big-O, Big-Omega, and Big-Theta notation with algorithm examples and a growth-function chart.

## Project folder

- `index.html` — webpage content and concept map
- `style.css` — colors, layout, responsive design
- `script.js` — interactive growth-function chart
- `README.md` — project instructions

## How to run in VS Code

1. Extract `Asymptotic_Growth_Comparison.zip`.
2. Open the extracted folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the **Live Server** extension and click **Go Live**.
4. Change the input size `n` in the Growth Function Explorer to compare the curves.

No installation or build step is required. An internet connection is only needed to load the optional Google Font; the project works without it.

## Concepts covered

- **Big-O:** asymptotic upper bound
- **Big-Omega:** asymptotic lower bound
- **Big-Theta:** asymptotically tight bound
- Growth functions: `1`, `log n`, `n`, `n log n`, and `n²`
- Examples: array access, binary search, linear search, merge sort, nested loops

## Note

The chart shows illustrative function values, not measured execution times. Big-O, Big-Omega, and Big-Theta are formal mathematical bounds; best/worst-case algorithm descriptions should be stated separately from the notation.
