PROJECT 4: JOB SEQUENCING WITH DEADLINES

Aim:
To schedule jobs with deadlines and profits so that the total profit is maximized.

Algorithm:
1. Read n jobs. Each job has an ID, deadline, and profit.
2. Sort all jobs in descending order of profit.
3. Find the maximum deadline. Create that many empty time slots.
4. For each job in sorted order:
   a. Start from the smaller of its deadline and the last available slot.
   b. Search backward for an empty slot.
   c. If an empty slot is found, place the job there and add its profit.
   d. If no slot is available, skip the job.
5. Display the scheduled jobs and total profit.

Pseudocode:
JobSequencing(jobs):
    Sort jobs by profit in descending order
    D = min(maximum deadline, number of jobs)
    Create D empty slots
    totalProfit = 0
    For each job in sorted jobs:
        For slot from min(job.deadline, D) down to 1:
            If slot is empty:
                slots[slot] = job
                totalProfit = totalProfit + job.profit
                Break
    Display slots and totalProfit

Sample input:
5
a 2 100
b 1 19
c 2 27
d 1 25
e 3 15

Expected result:
Schedule: a, c, e
Total profit: 142

Time complexity:
O(n log n + nD), where n is the number of jobs and D is the maximum relevant deadline.

Space complexity:
O(D) for the time-slot array.

Note:
This is the standard greedy job sequencing approach for unit-time jobs with deadlines.
