Sum of Subsets

State Space Tree using Inclusion and Exclusion

SET{5, 10, 12}
TARGET SUM15
VALID SUBSET{5, 10}

Each level considers one number. Choose Include or Exclude.

Solution (sum = 15) Not a solution Branch decision

How to read the tree

  1. Start with sum 0 and an empty subset.
  2. At each level, branch into Include the current number or Exclude it.
  3. If the sum becomes 15, a solution is found.
  4. The subset {5, 10} gives 5 + 10 = 15. The other branches do not reach the target.

Result: The subset that satisfies the target sum is {5, 10}.
