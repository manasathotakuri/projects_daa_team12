# Sum of Subsets — State Space Tree

A beginner-friendly mini project that draws the state space tree for finding a subset of `{5, 10, 12}` whose sum is `15`.

## Requirements
- Visual Studio Code
- Any modern web browser
- Optional: VS Code **Live Server** extension

## Run in VS Code
1. Extract `sum_of_subsets_tree.zip`.
2. Open VS Code.
3. Select **File → Open Folder** and choose `sum_of_subsets_tree`.
4. Open `index.html`.
5. Either right-click `index.html` and choose **Open with Live Server**, or open the file directly in your browser.

No installation commands or external libraries are required.

## Expected result
The page shows the state space tree with Include/Exclude branches. The valid subset is `{5, 10}` because `5 + 10 = 15`.

## Project files
- `index.html` — page structure
- `style.css` — layout and colors
- `script.js` — builds and displays the tree
