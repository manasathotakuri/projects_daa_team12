Job Sequencing with Deadlines

A Greedy Algorithm Visualizer

How it works

Each job has a deadline and a profit. The algorithm sorts jobs by profit (highest first), then places each job in the latest available time slot before its deadline. The goal is to maximize total profit.

Algorithm pseudocode

JobSequencing(jobs):
  Sort jobs by profit in descending order
  maxDeadline = maximum deadline among jobs
  Create empty time slots from 1 to maxDeadline
  For each job in sorted jobs:
    For slot = min(job.deadline, maxDeadline) down to 1:
      If slot is empty:
        Schedule job in slot
        Add job.profit to total profit
        Break
  Return schedule and total profit

Complexity

Time: O(n log n + nD), where n is the number of jobs and D is the maximum deadline.

Space: O(D) for the time-slot schedule, excluding the input and sorting storage.
